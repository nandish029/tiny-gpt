# Project Specification

1. GPT-1: Complete working tiny GPT baseline.
2. GPT-2: Improve training/optimization without changing the fundamental architecture.
3. GPT-3: Improve text representation using subword tokenization.
4. GPT-4: Optimize/select the final model architecture.
5. GPT-5: Freeze the GPT-4 architecture and train it extensively using more data and more training tokens.

- The project contains exactly five model versions.
- GPT-4 is the final architecture-development stage.
- GPT-5 must not introduce architectural changes.
- Features outside these goals are out of scope unless explicitly approved.
